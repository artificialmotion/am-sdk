# Security policy

## Reporting a vulnerability

Email **ayo@artificialmotion.com** with the subject "am-sdk security". Please do not open a public issue for a vulnerability.

Include what you found, the version or commit, and steps to reproduce. A proof of concept helps but is not required.

## What to expect

- We acknowledge a report within 5 working days.
- We assess it, tell you whether we agree, and keep you informed of progress.
- We aim to publish a fix within 90 days of the report. We coordinate the date of any public disclosure with you, and credit you in the release notes if you want that.
- Please give us reasonable time to fix the issue before you disclose it.

## Scope

This repository: the C library, the Python package, the simulators, the ROS 2 packages and the tools. The joint firmware is not in this repository; a firmware issue found through the SDK can be reported to the same address.

Only the latest release is supported while the SDK is 0.x.
